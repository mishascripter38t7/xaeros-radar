# Xaeros Radar

Статический гражданский интерфейс для отображения официальных региональных воздушных тревог и пользовательских геозон.

## Что уже есть
- интерактивная карта OpenStreetMap через Leaflet;
- рисование кругов, прямоугольников и многоугольников;
- локальное сохранение зон в браузере;
- список региональных событий;
- браузерные уведомления о новых активных региональных тревогах;
- GitHub Actions для публикации на GitHub Pages.

## Важно
Проект не отслеживает отдельные БПЛА или ракеты, не строит их траектории и не рассчитывает вероятность/время достижения конкретного дома. Это не заменяет официальные оповещения и инструкции экстренных служб.

## Запуск
Можно открыть `index.html` локально, но для корректной работы геолокации и некоторых функций удобнее запустить через локальный веб-сервер или GitHub Pages.

## Подключение источника данных
1. Откройте `config.js`.
2. Укажите `alertsApiUrl` — HTTPS-адрес совместимого API.
3. API должен разрешать браузерные запросы (CORS) и возвращать массив в формате:

```json
[
  {
    "region": "Запорожская область",
    "active": true,
    "updatedAt": "2026-11-22T12:00:00Z"
  }
]
```

Поле `coordinates` необязательно и предназначено только для координаты регионального маркера, не для объектов или траекторий:

```json
{"region":"Запорожская область","active":true,"coordinates":[47.84,35.14]}
```

Не вставляйте приватные API-ключи в `config.js`: репозиторий и опубликованный сайт могут быть публичными. Если провайдер требует секретный ключ, нужен отдельный серверный посредник с защищённым секретом; GitHub Pages сам по себе не выполняет серверный код.

## Публикация на GitHub Pages
1. Создайте репозиторий `xaeros-radar`.
2. Распакуйте архив в корень репозитория (чтобы `index.html` лежал прямо в корне).
3. Загрузите файлы в ветку `main`.
4. В GitHub откройте **Settings → Pages** и выберите **GitHub Actions** как источник публикации.
5. После успешного workflow сайт будет доступен по адресу GitHub Pages вашего репозитория.

## Бесплатные картографические данные
Карта использует тайлы OpenStreetMap. Соблюдайте политику использования тайлов и атрибуцию OpenStreetMap; для большой посещаемости выберите подходящего провайдера тайлов.
